# sdcard_bridge

**Status**: Aktif (Produksi)
**Kategori**: IoT — SD Card Bridge

## Deskripsi
Bridge pembaca SD card berbasis Rust. Membaca data presensi dari SD card mesin absensi lama dan mengimpor ke sistem presensi baru.

## Tech Stack
- Rust
- src/ untuk kode utama
- firmware/ untuk companion firmware

## Catatan
- Cargo.lock/Cargo.toml: Rust project
- Berguna untuk migrasi data dari mesin absensi lama
